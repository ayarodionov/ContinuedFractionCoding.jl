Continued-Fraction Coder

Animated runs of cf_encode / cf_decode from ContinuedFractionCoding.jl. A message of integers a₁, a₂, … ≥ 1 is read as the continued fraction x = [0; a₁, a₂, …]. Encode narrows [0, 1) to the cylinder of reals whose expansion starts with the message, then writes a short binary point inside it after an Elias-gamma length header. Decode rebuilds that point and reads the quotients back with the Gauss map t ← 1/t − ⌊1/t⌋. Both traces match the Julia coder bit for bit.

Reading the picture

Top: the unit interval, with the current cylinder highlighted. It shrinks fast (a quotient a costs about 2 log₂ a bits), so the middle bar shows it magnified to full width.

Bottom: the Gauss coordinate t = Tⁿ(x), where T(t) = 1/t − ⌊1/t⌋. Inside the cylinder [0; a₁, …, aₙ], x = (hₙ + t·hₙ₋₁) / (kₙ + t·kₙ₋₁) from the convergents. In t the next split is always the same: quotient a owns (1/(a+1), 1/a]. The grey lines carry each piece from t to x; at odd depth they cross, because x decreases as t grows.

Measured with the Gauss measure dt / ((1+t) ln 2), the piece of a has probability log₂(1 + 1/(a(a+2))) at every depth. That is why this coder is exact for the Gauss–Kuzmin source and a fixed code for everything else.

The coder is a batch coder: it builds the whole cylinder with exact BigInt convergents and writes its point at the end. The dashed chips show which leading bits are already settled along the way.
