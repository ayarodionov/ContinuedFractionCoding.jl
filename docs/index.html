Continued-fraction coding, animated

Step-by-step runs of the coder from ContinuedFractionCoding.jl. Encoding narrows [0, 1) to the cylinder of a continued fraction and writes a binary point inside it; decoding reads the quotients back with the Gauss map. The traces match the Julia coder bit for bit.

EncodeCylinders, the Gauss coordinate, and the dyadic point. DecodeElias-gamma header, then the Gauss map t ← 1/t − ⌊1/t⌋.

Companion to the p-adic coder animations.
